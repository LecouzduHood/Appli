# Notes de devis

Petite application (PWA) pour prendre des notes chez le client lors des devis :
rénovation électrique, rénovation complète (tout corps d'état), intervention électrique.

Ouvrir sur l'iPhone : https://lecouzduhood.github.io/Appli/ puis « Ajouter à l'écran d'accueil ».

Les devis sont enregistrés sur le téléphone (localStorage). Le catalogue des prestations
se modifie en haut du script de `index.html` (PRESTATIONS, LOTS_TCE, PIECES_PRESTA, TYPES).
